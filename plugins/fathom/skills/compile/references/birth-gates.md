# Birth gates — which study level may compile which artifact section

The study's recorded gate (`progress.md`) is the sole authority. Un-reached territory is
omitted, never faked — every shell renders it as honest fog（「這條路 study 還沒鋪」）.

| Study gate reached | Artifact sections that may exist |
| --- | --- |
| Repository (`index` done) | **repo dashboard**（產物①, offered by `index` — lab pilot pending）· atlas fixture's `repo` scale（tiers · modules · imports · magnitudes） |
| Runtime / System (`guide`) | **state board**（產物②, offered at `guide`'s System gate — lab pilot pending）· atlas coarse behaviors, few steps, marked `provisional: true` |
| Behavior (`guide` / `dive` traces) | atlas full behaviors for the paths actually studied: routes · cargo edges · three-tier narration |
| Code | `peek` refinement · 常見誤解 annotations at line precision |

Enrichment is the normal case: every later gate makes a **recompile** add sections or deepen
existing ones (stable IDs, revision allowed). The fixture's diff between compiles reads as
"what the study learned since" — that is a feature, surface it in the compile report.
