# seek — plugin guide

Seek provides four small, independently usable methods:
- elicit clarifies the user's consequential choice or a supported cause.
- mockup makes a choice tangible through an operable comparison.
- probe tests a measurable claim or interprets existing evidence.
- dogfood uses a real workflow to locate reproducible friction and missing paths.

Choose the method from the uncertainty, without a required sequence. A short reply
or existing evidence can be sufficient. Findings do not authorize implementation.

Outputs can stay in chat or scratch. Save only on request or for concrete reuse;
the builder bundles the shared saving policy and workspace references on demand.
Read UI preferences for visual work and verify actual decision-critical interaction.
Browser checks use references/browser-check.md and the optional browser-verifier agent.
No mandatory record, screenshot sequence, question count, experiment count or retro.

The current evaluations did not establish a general advantage for full-size skills
over concise methods. These entrypoints remain explicit, lightweight experiments.
Roster rationale is in docs/adr/015-shape-entrance-roster.md.
