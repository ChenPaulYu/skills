# Optional execution dispatch

Read only when delegating a bounded task to a worker. Planning and acceptance stay with
the session model. Honor the user's existing authority and execution-tier choice.

Supply the goal, owned files, base state, source of truth, existing implementations to reuse,
preserved contracts, permitted changes, forbidden scope, and a checkable completion condition.
Tell the worker it shares the codebase and must preserve other edits. Include verification
commands and require status, files changed, actual checks/results, assumptions, unresolved risks,
and current revision in its return.

Inspect the actual diff, check consumers and duplicate implementations, and reproduce relevant
verification before accepting completion. Preserve behavioral assertions and check public
contracts, header hygiene, and tracked board updates. A self-report is not integration evidence;
do not delegate judgment to a second reviewer agent.

Report execution tier and count alongside the session's acceptance result.
