# ADR 132 — Load only the instructions a task needs

**Status**: accepted
**Date**: 2026-09-30
**Source**: the owner approved the skill simplification review.
**Amends**: ADR-109's layering application, ADR-126/128's authorized continuation,
and ADR-131's reconcile packaging. No task entrance is retired.

## Problem

The generated root AGENTS.md carried all four family guides even for a task touching one
family. Reconcile bundled blueprint authoring and HTML rendering material it did not use.
Compose still had a verbatim-rewrite restriction and a second approval implication after
the repository had adopted authorized continuation. Four frame bodies repeated taxonomy
and delivery narration. Digest loaded the complete fallback classifier on its normal
helper path; its arrival wording also suggested acting despite the read-only contract.

## Decision

- Root AGENTS.md contains shared editing rules and a generated index of source maintainer
  guides. Read the relevant family before editing it. Source guide links are appended after
  host translation so they reach their real owners. Runtime skills remain self-contained.
  Root incident narratives are shortened where linked ADRs already preserve the reasons.
- Reconcile loads its cleanup protocol and preserves the existing record format. Remove
  blueprint-spec and HTML-template bundles. The shared-reference builder removes retired
  bundles only under skill reference directories and only with its own exact first-line
  ownership marker; it does not follow symlinks or remove handwritten references.
- Compose preserves claims, decisions, qualifications, sources, and exact quotations.
  Concise rewrites may serve the requested structure. Preview the structure or diff, then
  complete authorized work; review-only stays read-only, and new authority still requires
  the user's decision. This changes prose restructuring, not code's observable contracts.
- Analogize keeps candidate comparison, structural mapping, and the boundary of the analogy.
  First-principles keeps verified premises, rebuilding, and comparison with convention.
  Orthogonal keeps the change-one/check-the-rest test. Dialectic keeps grounded opposing
  cases, inference checks, the pivotal uncertainty/test, and its three-way verdict. Existing
  examples remain on demand; fixed closing rituals and repeated introductions are removed.
- Digest uses its deterministic helper first. The full semantic contract moves verbatim
  into an on-demand fallback/diagnosis reference. Collection options move separately. The
  body preserves blocked/degraded reporting, revision validity, and the read-only boundary:
  arrival reports the next native action; it does not execute it. Classifier code is unchanged.
- Archive the verified legacy standalone mockup installation and its matching receipt entry
  outside discovery roots. Keep the maintained shape-mockup and a recovery copy. This is a
  local installation repair, not a new marketplace skill retirement or broad external sweep.

## Alternatives and limits

Keep the 24 entrances. Merging align, reconcile, and sync would again conflate priority,
record cleanup, and document accuracy. Deleting reasoning skills for short bodies alone
would confuse low instruction volume with low value. A new router or generic maintenance
framework adds no demonstrated capability here.

Character counts measure text reduction, not model token usage or output quality. Reference
extraction reduces the normal load only when the branch stays unloaded. Existing unit and
packaging tests plus source-contract comparison do not establish blind behavioral superiority;
real routing and task-completion evidence must come from subsequent use.
