Skills — marketplace map

Personal Claude marketplace. A growing collection of focused, single-purpose plugins for keeping code navigable as it grows. Three layers: a marketplace (the container) holds plugins (topical families) which hold skills (the verbs you actually invoke).

How to read this: scroll for a 30-second overview, or jump to any section from the left. Every domain graph is interactive — click a node for its details, drag to rearrange.

Built on Ousterhout's deep-module principles. Self-contained skills (no shared imports). Language-agnostic (universal core + per-stack heuristics).

Install — one source tree, five agents

Three channels: Claude Code and agy import the plugins natively (namespaced /<plugin>:<verb>); Codex and opencode auto-discover the flat mirror .agents/skills/; Cursor installs generated Cursor Plugins. Shortcut for any harness — tell your agent: “Fetch and follow instructions from https://raw.githubusercontent.com/ChenPaulYu/skills/main/INSTALL.md”. Or by hand, in Claude Code:

/plugin marketplace add ChenPaulYu/skills
/plugin install nav@skills        # + shape@skills · frame@skills

In Antigravity CLI (agy) — native Claude Code plugin import, same namespace, no conversion. Clone the repo, then:

agy plugin install plugins/nav    # + plugins/shape · plugins/frame

Codex and opencode need no install step inside this repo — both auto-discover the generated flat mirror .agents/skills/ (nav:audit → nav-audit). For global use, run node scripts/build-codex.mjs --sync-global --profile build --dedupe-global-roots. See README → Codex compatibility.

Two more routes: the skills.sh CLI (npx skills add ChenPaulYu/skills — pick the prefixed skill set), and Cursor's native plugins — node scripts/build-cursor.mjs --sync-local (flattened names inside generated Cursor Plugins; not the Codex mirror). Full guides: README → Install.

Iterating on this marketplace itself? Use a local absolute path instead of the GitHub handle — see README → Local development.

Architecture — three layers, one container

The marketplace registers via .claude-plugin/marketplace.json and lists which plugins live inside. Each plugin declares itself via .claude-plugin/plugin.json and exposes skills under skills/<verb>/SKILL.md. Slash commands surface as /<plugin>:<skill>.

Design rules — the bar every skill clears

Ousterhout-derived deep-module principles + extensions for grounding and agent-navigability. This is the current live summary; historical audit entries below may quote older versions.

Skill list — search & expand

★ marks load-bearing / read-first. The skill name is the slash command you invoke (/<plugin>:<skill>).

plugin nav — audit, implement, ship

Audit assesses architecture. Do implements, refactors and checks explanations. Ship verifies and lands the selected release.
Use shape-add to define the deliverables and acceptance checks. nav-do implements authorized decided work, including multi-item tasks. Ask nav-do for the engineering approach first when you want to review it before building.

plugin shape — add, view, next, tend

Add captures ideas and work. View reads progress. Next advances authorized work. Tend maintains project records.
Keep progress in the original task. Save independent records only when they have a purpose. Seek owns clarification, comparisons, experiments and real-use reviews.
