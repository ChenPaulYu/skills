# compile — turn the study into its artifacts

The fifth verb: **index 測深、guide 教學、dive 深追、quiz 保溫 — compile 成圖**. The study is the
source; each artifact is a build product; this door is the compiler. Compiling is
**re-creation, not transcription** (教學是再創作), and every fact must survive verification
against the pinned source.

Fifth-verb evidence (per the plugin's own bar): a compile fires *outside* every existing door's
moment — after a dive, on returning to a stale study, or on a bare "生成 horizon" with no teaching
in flight — and the atlas half was validated across four studies before this door landed. Binding
the artifacts to their birth gates instead (horizon inside `index`, tides inside `guide`) was tried
and rejected: it conflates *when an artifact may first exist* (data — `birth-gates.md`) with *when
someone wants it compiled* (any time). `index`/`guide` keep a one-line offer pointing here; they
own no compiler machinery.

## Three artifacts, one machine

| Artifact | Level | What it answers | Status |
| --- | --- | --- | --- |
| **horizon** | Repository | 這是什麼、信不信得過、能力長什麼樣 | pilot (lab-side; briefs land here on graduation) |
| **tides** | System / State | 狀態住哪、誰擁有、一次觸發的增量 | pilot (lab-side) |
| **atlas** | Behavior / Code | 一次執行怎麼走、每跳傳什麼、code 在哪 | **graduated** — `references/atlas-protocol.md` |

They are separate products with separate schemas and shells — never one mega-fixture. What they
share is this door and the machine below.

## Which artifact? — resolve, don't guess

The gate says what is *possible*; the request and the stamps say what is *wanted*. Resolve in this
order, and **always name the choice before compiling**:

1. **Named target wins.** `compile horizon` · 「重編一下地圖」(→ atlas) · 「system 那層再編一次」
   (→ tides). Artifact vocabulary: horizon = 儀表板/repo 級 · tides = 狀態板/system 級 ·
   atlas = 地圖/behavior 級.
2. **Fresh context, if the request is bare.** A gate just passed, a dive just ended, a teaching
   session just closed → the artifact tied to that level, plus anything it made stale.
3. **Otherwise compute the plan from the stamps** — cheap, deterministic, no guessing. Read each
   existing fixture's `meta.studyGate` / `meta.compiledAt` and the study's `progress.md`:

   | State | Meaning | Bare `compile` does |
   | --- | --- | --- |
   | **missing** | the gate unlocks it, no fixture exists | compile it |
   | **stale** | fixture's `studyGate` is shallower than the study's current gate | recompile it |
   | **current** | stamped at the study's gate | leave it (recompile only if named) |

   Report the plan (`horizon: stale → recompile · atlas: missing → compile`) before spending
   anything; a full compile is expensive, so silence is not an option.

**Order matters when several are due: shallow → deep (horizon → tides → atlas).** The artifacts
overlap — horizon's dependency groups and atlas's repo-poster tiers describe the same modules —
so the shallower fixture is passed to the deeper compile as a naming seed. Compiling deep-first
lets the same repo grow two different vocabularies, which is the artifact layer's own version of
information leakage.

## The compile, end to end

1. **Resolve the study and its gate.** `studies/<name>/` must exist with a pinned clone;
   `progress.md` names the deepest level actually reached. The gate decides which artifacts — and
   which sections of each — may exist ([`references/birth-gates.md`](references/birth-gates.md)).
   Never compile above the recorded gate; honest fog is the product's feature, not a gap.
   **Also check `understanding.md` — artifacts are teaching material, and material authored
   without a learner model is authored for nobody.** Missing or empty → say so *before* compiling
   and offer to calibrate first — the protocol belongs to `fathom-guide` (two axes plus the
   narration probe that seeds the Corrected table, the only legitimate source of 「常見誤解」
   annotations); run it there, or run the same two axes inline when the learner is here now. Compiling anyway is allowed — the learner
   may be absent — but the report and the fixture's provenance must both state that it was
   authored for a generic reader. Inferring the learner from side channels is **not** a
   substitute, and a calibration that arrives *after* a compile makes that compile a re-compile
   candidate: record what is now known to be mis-aimed in `understanding.md`.
2. **Mechanical layer first.** `node scripts/scan-repo.mjs <sourceRoot> <rootDir> [--lang=python|js]`
   produces magnitudes and import edges. The model never authors these numbers.
3. **Two-pass loop** (tiers per the household dispatch rules — creation is judgment-dense,
   verification is mechanical; **if the strong tier is unavailable, do the create pass in the
   session model rather than downgrading it** — narration quality is the artifact's entire value,
   while verification degrades gracefully), governed by
   [`references/compile-loop.md`](references/compile-loop.md):
   - **Read the form ledger first** (`studies/_forms-ledger.md`) — it names the shapes that have
     already failed to fit, so this compile reuses an existing shape-key instead of minting a
     synonym. Reading before authoring is what makes step 6's tally meaningful.
   - **Create** (strong tier) against the artifact's protocol + brief — for atlas,
     [`atlas-protocol.md`](references/atlas-protocol.md) and
     [`atlas-brief-create.md`](references/atlas-brief-create.md). Seeds = the study's `index.md`
     soundings, tours, notes, learner model's Corrected table; ground truth = the pinned clone
     only. A prior fixture carries stable IDs forward.
   - **A dispatch that died is not a compile that failed.** A create pass can be terminated
     (rate limit, timeout, crash) *after* writing the fixture and *before* reporting — it happened
     on 2026-08-15 and the artifact was complete. Before re-dispatching anything: check the file
     on disk, run the gate, and diff against the prior version. Re-running a finished compile
     costs a full creation budget for nothing.
   - **Gate**: `node scripts/validate-fixture.mjs <fixture>` must PASS before anything else sees
     the file.
   - **Verify** (cheap tier) — [`atlas-brief-verify.md`](references/atlas-brief-verify.md): every
     line range, io, edge, magnitude re-checked against source. Loop create←verify until the
     defect list is empty. (Measured: unverified contribution = 9 defects shipped; brief-hardened
     verified compile = 0.)
4. **Deploy + render.** Ensure the artifact's shell is deployed at the workspace (copy from
   [`assets/shells/`](assets/shells/) when absent or older — deployed copies are instances, the
   skill asset is canonical). Serve the workspace root (shells fetch `<study>/source/…`), open the
   shell with `?fixture=…`, and do one browser pass before reporting the URL.
   **Cache-bust the FIXTURE, not just the page.** The shell's URL and the fixture's URL cache
   separately, so a recompile opened with a fresh page query still renders the previous JSON —
   which looks exactly like a compile that changed nothing. Append a version marker to the fixture
   path itself (`?fixture=/path/horizon.gen.json%3Fv=2`) when verifying any recompile.
   (2026-08-15: a stale render was nearly reported as the new artifact.)
5. **Report**: the URL(s), what this compile added or revised versus the prior fixture (the diff IS
   the study's progress), and any uncertainty the verifier left standing.
6. **Record what didn't fit.** Every compile that had to inline something into prose, invent a
   slot, or drop a fact because no field could hold it appends a row to the workspace's form
   ledger (`studies/_forms-ledger.md`) with a **shape-key**. Then run
   `node scripts/forms-ledger.mjs` and surface anything ripe (3+ distinct studies) in the report.
   This step is not optional: recurrence that lives only in conversation is never counted, and an
   uncounted invariant never graduates. Procedure and promotion rules:
   [`references/form-growth.md`](references/form-growth.md).

## Stance

- **Purely semantic fixtures; shells own layout.** No coordinates in the data, ever — structure in,
  geometry out. The five hard rules every session must obey before writing a fixture live in
  [`compile-loop.md`](references/compile-loop.md); the per-artifact authoring law lives in that
  artifact's protocol.
- **Revision allowed, identity never.** A recompile may rewrite prose a deeper study corrected; it
  never churns ids and never drops a studied section unasked.
- **One-way dependency.** Artifacts read the study; nothing in the study ever depends on them.
- **Forms grow by evidence, never by fiat.** What an artifact cannot hold goes into a marked
  `bespoke` block and a ledger row — not into a forked skeleton, and not into loosening the schema
  until it can express anything. Three distinct studies promote a shape; fewer is an idiosyncrasy.
  Full procedure: [`references/form-growth.md`](references/form-growth.md).
- **Learner-facing strings 繁體中文（台灣用語）**; identifiers, paths, code stay English.

## Communication style

- Precise technical detail after, only where needed.
