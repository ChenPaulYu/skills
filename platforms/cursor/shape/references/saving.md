# Keep only what a future reader needs

A conversation, experiment or comparison can finish in chat. Default to no new record.
Save an idea or thought when the user asks, preserving their meaning and using the
selected home's existing convention. A saved idea grants no execution authority.

For work that must continue across rounds, reuse the original task. Keep its scope and
authorization, verified result and limits, operative reason, next action and user-owned
gate. Link an exact test/commit when possible instead of copying a tool transcript.
One-off work that is recoverable from code and Git needs no new task.

Put a reason in its task unless it has independent reuse or an explicit save destination.
Retained project knowledge belongs in docs; temporary exploration can use a working
thought with an exit condition. Follow the retained-doc/working-thought contract in
references/workspace-records.md. Neither a new document nor a thought is mandatory.
A retained experiment merits its own finding only when its method/data will inform a
future decision or reproduction. Keep an actual artifact when the user requests it or
when its original state is needed to compare or reproduce; a URL/hash alone cannot
satisfy an explicit save request.

Resolve the configured home using references/workspace-records.md and obey its policy.
Reuse existing owners and formats; no automatic directory migration or cleanup.
Use references/record-interface.md only when writing a retained record, and
references/development-artifacts.md before selecting or saving an artifact. Never create a duplicate
progress board or handoff to satisfy a procedure.
